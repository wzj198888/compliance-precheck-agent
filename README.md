# SME Compliance Precheck Agent

面向中小企业合同、采购与报销场景的轻量级合规预审 Agent 原型。

该项目用于验证一种低 token、高频审批预审工作流：不把完整制度库和历史案例全部塞进上下文，而是采用“任务识别 -> 字段抽取 -> 精准检索 -> 规则核查 -> 结构化报告”的分段流程，在较低单次成本下完成企业日常审批材料的预审。

## 适用场景

- 合同初审：合同金额、付款比例、验收条款、发票类型、违约责任、附件清单检查
- 采购申请：采购金额、供应商、预算科目、比价材料、审批权限检查
- 费用报销：报销金额、发票类型、预算科目、附件完整性、超标准风险检查
- 项目立项：预算、周期、供应商、验收条件、审批材料检查

## 核心模块

1. **任务识别 Agent**
   - 判断材料属于合同初审、采购申请、费用报销或项目立项。
   - 预计消耗 1600-2500 token。

2. **字段抽取 Agent**
   - 提取采购金额、供应商、预算科目、合同金额、付款比例、验收条件、发票类型、附件清单等字段。
   - 费用报销约 2000-3300 token。
   - 采购申请约 3200-5000 token。
   - 普通合同约 6000-10500 token。

3. **制度检索 Agent**
   - 按任务类型和关键字段检索最相关的 3-5 条制度片段。
   - 避免整本文档进入上下文。
   - 单次约 2800-5400 token。

4. **规则核查 Agent**
   - 检查金额超权限、缺少比价材料、付款比例过高、验收条款缺失、发票类型不匹配、附件不完整等问题。
   - 单次约 3800-7700 token。

5. **报告生成 Agent**
   - 输出预审结论、关键字段摘要、主要风险点、制度依据、需补充材料和修改建议。
   - 单次约 3200-6300 token。

## Token 预算

| 材料类型 | 单次预计 token |
| --- | ---: |
| 普通费用报销预审 | 13,000-21,000 |
| 采购申请预审 | 16,000-25,000 |
| 普通合同初审 | 20,000-34,000 |
| 项目立项预审 | 23,000-37,000 |
| 复杂长合同 | 40,000-60,000 |

原型测试阶段计划 1 个月完成约 200 份模拟审批材料测试，包括 80 份报销、60 份采购、40 份合同和 20 份项目立项，并进行约 100 次制度问答、边界案例测试和 prompt 优化，预计总需求约 600 万-800 万 token。

试运行阶段覆盖 500-1000 份材料并进行规则召回率、风险识别准确率和报告质量评估，预计需要 1500 万-3000 万 token/月。

## 快速开始

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m compliance_precheck samples/reimbursement_case.json
python -m compliance_precheck samples/procurement_case.json
python -m compliance_precheck samples/contract_case.json
```

## 示例输出

运行后会输出结构化 JSON 报告：

- 任务类型
- 关键字段摘要
- 命中的制度依据
- 风险等级
- 风险点
- 需补充材料
- 修改建议
- token 预算估算

## 定位说明

本系统不替代最终审批，只承担审批前规则核查和风险提示。目标是把单份材料人工预审时间从 15-30 分钟降低到 2-5 分钟，提高材料一次提交质量，减少因制度误读、附件缺失和合同条款遗漏造成的退回修改。
